# YFVL SRS mirror

Public, unmodified routing-rule binaries. No subscriptions, user data, private generator code, or Yandex resources. This is a partial mirror: 13 files; direct-ip is intentionally excluded pending confirmation of redistribution rights.

## Provenance and corresponding sources

See sources.json and seed-provenance.json for the exact repository, revision, file, Git blob and license for each seed. The original upstream build scripts, source lists and associated notices are available at the following upstream projects. The mirror distributes unmodified bytes and retains the original licensing and copyright notices. For GPL-covered binaries, the corresponding source and build instructions are available from the linked upstream repositories; exact binary upstream revisions are in the provenance/manifest.

- [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) — GPL-3.0; source and build scripts on master, binaries on sing.
- [Chocolate4U/Iran-sing-box-rules](https://github.com/Chocolate4U/Iran-sing-box-rules) — GPL-3.0; source on main, binaries on rule-set.
- [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat) — GPL-3.0; source on main, binaries on release.
- [hydraponique/roscomvpn-geosite](https://github.com/hydraponique/roscomvpn-geosite) — MIT, Copyright (c) 2018–2019 V2Ray.
- [KaringX/karing-ruleset](https://github.com/KaringX/karing-ruleset) — initial comparison source for the exact matching blobs.

Full license texts are in LICENSES/. Individual rules retain their original licenses; no blanket license overrides them.

## Validation and updates

The initial seed is not production-ready until manifest.json has been generated by the pinned LX validator. Daily refresh resolves immutable upstream revisions, checks Git blob SHA, binary validity and semantic type, decompiles each rule, checks required OpenAI domains, rejects large unexpected reductions, and records SHA256. A failed download/validation leaves the previous commit unchanged. No cloud storage, external credentials or private repository access required. GitHub history preserves prior validated generations.

Use anonymous raw URLs only after initial validation passes. GitHub reachability on the client remains necessary for a cold start with no cache.
